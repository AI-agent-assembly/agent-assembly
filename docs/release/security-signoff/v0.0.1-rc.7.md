| Low | `aa-gateway`'s dashboard-facing `IamApiKeyStore` generates secrets with a non-cryptographic PRNG (`DefaultHasher`-seeded LCG) | accepted-with-justification — independently verified unreachable from any enforcing auth path in the current codebase (the real enforcing `aa-auth::api_key::ApiKeyStore` uses a genuine RNG); the code's own doc comment already tracks this as a placeholder pending a CSPRNG swap before any future wiring into an enforcing path |
| Low | `aa-runtime`'s boot-time capability self-check (`effective_forbidden_caps`) treats an unreadable `/proc/self/status` as "holds nothing forbidden" rather than failing closed | accepted-with-justification — independently verified this check runs exactly once at boot, before the runtime opens its Unix socket to any agent connection; not attacker-triggerable, defense-in-depth backstop behind the primary bounding-set-drop mitigation |
